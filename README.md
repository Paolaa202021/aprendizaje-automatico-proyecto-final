Segmentación de Siniestros Viales mediante K-Means

Proyecto Final de Aprendizaje Automático.

Objetivo:
Identificar patrones y agrupamientos de siniestros viales utilizando técnicas de aprendizaje no supervisado mediante K-Means.

Dataset:
Registros de siniestros viales ocurridos en autopistas urbanas durante el año 2024.
